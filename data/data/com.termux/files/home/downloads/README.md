
# Karlfine AI (Termux ChatGPT CLI)

Karlfine is a lightweight ChatGPT-style terminal assistant designed for Termux.

## Install

```bash
git clone https://github.com/Karlfiner-Robotiken/Karlfine.git
cd Karlfine
bash install.sh
```

## Run

```bash
export OPENAI_API_KEY=your_api_key
karlfine
```

## Features

- ChatGPT terminal interface
- Termux compatible
- Conversation memory
- Extendable plugin architecture
